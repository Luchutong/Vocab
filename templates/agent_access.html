2

直接调用 HTTP API

适用于脚本、自动化平台，或能够自行发送 HTTP 请求的 Agent。

接口地址 {{ api_base_url }}/api/agent/import

curl 示例

export VOCAB_API_TOKEN='{{ token_example }}'

curl '{{ api_base_url }}/api/agent/import' \
  -H "Authorization: Bearer $VOCAB_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $(cat /proc/sys/kernel/random/uuid)" \
  --data '{"words":["abandon","dense","elapse"]}'

请求字段

位置名称要求
HeaderAuthorization必须为 Bearer 个人Token
HeaderIdempotency-Key建议设置。重试时复用同一个值，避免重复记录复习
JSONwords非空字符串数组，单次最多 100 个单词

返回结果示例

{
  "ok": true,
  "imported_count": 3,
  "failed_count": 0,
  "imported": [
    {
      "word": "dense",
      "definition": "密集的；浓厚的",
      "created": true,
      "next_review": "2026-06-17"
    }
  ],
  "failed": []
}

批量中某个单词失败不会回滚其他有效单词。失败项会附带原因和可能的拼写建议。

3

配置 stdio MCP

MCP 程序运行在 Agent 所在电脑，通过 HTTPS 调用本站，不需要在服务器额外开放 MCP 端口。

3.1 获取适配器并安装依赖

git clone https://github.com/Luchutong/Vocab.git
cd Vocab
python3 -m venv venv-mcp
venv-mcp/bin/pip install -r requirements-mcp.txt

3.2 创建仅当前用户可读的环境文件

mkdir -p ~/.config
cat > ~/.config/vocab-mcp.env <<'EOF'
VOCAB_API_URL={{ api_base_url }}
VOCAB_API_TOKEN={{ token_example }}
VOCAB_API_TIMEOUT=30
EOF
chmod 600 ~/.config/vocab-mcp.env

3.3 添加到 Agent 的 MCP 配置

将下面的 /绝对路径/Vocab 替换为仓库真实路径。Windows 用户可在 WSL 中使用同一配置。

{
  "mcpServers": {
    "vocab-builder": {
      "command": "/bin/bash",
      "args": [
        "-lc",
        "set -a; source ~/.config/vocab-mcp.env; exec /绝对路径/Vocab/venv-mcp/bin/python /绝对路径/Vocab/mcp_server.py"
      ]
    }
  }
}
配置完成后需要重启 Agent 客户端。 成功连接后，应看到名为 import_words 的工具。
4

验证配置

先用一个测试单词确认链路，避免一次提交大量内容后才发现配置错误。

  1. 向 Agent 提出：“请使用 vocab-builder 的 import_words 工具导入 abandon。”
  2. Agent 应返回导入数量、中文释义以及是否为新词。
  3. 刷新本站“今日测验”，该单词应出现在当天待复习列表中。
  4. 再次导入同一单词不会重复创建词条，但会按一次新的导入复习记录处理。

不要要求 Agent 在回复中复述 Token。工具只需要读取环境变量，不需要知道或展示密钥内容。

5

常见问题

按 HTTP 状态码或 MCP 报错信息快速定位。

401：Agent Token 无效或已撤销

检查环境文件中的 Token 是否完整，确认没有多余引号或空格，并在本页确认该 Token 仍处于有效状态。Token 丢失时请撤销旧 Token 并重新创建。

404 或连接失败

确认 VOCAB_API_URL 只填写站点根地址，不要附加 /api/agent/import；确认域名可从 Agent 所在设备访问。

证书验证失败

应为站点配置可信 HTTPS 证书和完整证书链。不要通过关闭 TLS 校验来绕过问题，也不要通过公网 HTTP 发送 Token。

Agent 看不到 import_words 工具

确认使用绝对路径，执行 venv-mcp/bin/pip install -r requirements-mcp.txt，然后完全退出并重启 Agent 客户端。

单词没有导入

服务端只接受本地词典能够确认的英文单词。查看返回值中的 failed 和 suggestions，修正拼写后重新提交。

有效 Token

建议每台设备使用独立 Token。撤销操作立即生效，不会删除已经导入的单词。
