# 六级词汇复习系统 - 开发规约

## 项目概述

构建面向天津大学用户的 CET-6 英语词汇学习网站。后端使用 Flask，
数据存储使用 SQLite，监听 `0.0.0.0:6657`。所有页面、提示和按钮使用中文。

## 1. 账户系统

- 仅允许 `@tju.edu.cn` 邮箱注册，不接受子域名。
- 密码至少 8 位并使用安全哈希存储。
- 注册后必须通过邮件链接验证，验证链接有效期 24 小时。
- 支持登录、退出、重发验证邮件、忘记密码和邮件重置密码。
- 密码重置链接有效期 1 小时。
- SMTP 与 `SECRET_KEY` 通过环境变量配置。
- SMTP 支持 `ssl`、`starttls` 和 `plain`；天大邮箱服务器部署默认推荐
  `smtp.tju.edu.cn:465 + ssl`。
- 邮件发送失败时保留未验证账户，允许稍后重发。
- 除账户相关公开页面外，业务路由必须验证登录和邮箱状态。

## 2. 多用户数据隔离

- `users` 保存账户邮箱、密码哈希、验证状态和注册时间。
- `words`、`review_log`、`user_settings` 必须关联 `user_id`。
- 单词以 `(user_id, word)` 唯一，不同用户的数据完全隔离。
- 所有资源查询、更新和删除必须同时检查当前用户归属。
- 每位用户的每日复习上限默认 30，可在仪表盘修改。

## 3. 词典与拼写检查

- 完整 ECDICT SQLite 数据库为默认主词典，路径为 `data/ecdict.db`。
- 精确词条未命中时使用 ECDICT `exchange` 字段查询原形。
- 本地释义去除纯英文行、重复项和冗余词性前缀，并限制展示长度。
- 拼写建议优先从完整本地词表生成。
- Merriam-Webster、MyMemory、DictionaryAPI.dev 和 Datamuse 仅作为可选兜底。
- 正常查询不得依赖网络或消耗在线 API 配额。
- 提供命令 `flask --app app download-dictionary` 下载完整 ECDICT。
- 查询返回中文释义、音标和词性。
- 查询不到时禁止导入，并返回相近拼写候选词。
- 单词仅允许英文字母，以及合理的连字符和撇号。

## 4. 交互式单词导入

- 独立页面：`GET /import`。
- 使用原生 JavaScript 和 Fetch API，无刷新连续录入。
- 第一次回车查询词典并展示词义、音标和词性。
- 第二次回车确认导入，完成后自动清空并聚焦输入框。
- 查询结果使用带时效的一次性服务端签名令牌，禁止客户端伪造。
- 新词创建后立即按 SM-2 `quality=3` 记录一次今日复习。
- 已有词不重复创建、不覆盖释义，但同样按 `quality=3` 记录复习。
- 提供个人 Agent Token 和批量导入 API；Token 明文只展示一次，数据库仅保存摘要。
- Agent API 复用服务端词典校验与导入逻辑，不允许客户端提交释义。
- Agent API 支持幂等键，单批最多 100 个，可由用户随时撤销 Token。
- 手工、Agent 或资料广场导入的单词均进入当天正式测验，包括尚未到期的已有词。
- 页面侧栏展示当天首次加入词库的单词。

## 5. 资料广场

- 导航包含资料广场，资料只对已登录且验证邮箱的用户可见。
- 资料 PDF 位于 `MATERIALS_DIR`，默认 `data/materials`，不提交 Git。
- 启动时自动扫描文本型 PDF，使用 PyMuPDF 提取整卷文本并写入 `materials` 表。
- 以 PDF 内容 SHA-256 去重；同名文件内容变化时更新资料记录。
- 扫描型或无法提取足够英文文本的 PDF 跳过并记录日志，不影响应用启动。
- v1 展示整卷文本，不按题型拆分，不开放用户上传。
- 阅读页按段落展示文本，英文单词可点击，点击后显示浮层释义卡片。
- 浮层可将单词加入当天生词，导入来源记录为 `material_import`。

## 6. 间隔复习

- 使用 SM-2 算法，默认 EF 为 2.5，最低 EF 为 1.3。
- 评分为牢记 5、一般 3、模糊 2、遗忘 0。
- 掌握时首次间隔 1 天、第二次 3 天，之后按旧 EF 乘以前次间隔。
- 遗忘时间隔重置为 1 天、重复次数归零，并累计遗忘次数。
- 正式测验逐词输入中文释义，按释义关键词判定。
- 30% 概率展示原词的变形形式。
- 变形必须由 ECDICT `exchange` 明确提供、目标词条真实存在且符合原词主词性；
  禁止使用拼写规则猜测不存在或罕见词形。
- 检查答案时逐项展示原形和已验证变形的类型、形式。
- 每日测验受用户设置的复习上限约束。
- 中断超过一天时，对过期词按风险排序并分配到未来日期。

## 7. 仪表盘与词库

- 展示今日待复习、今日已复习、今日新学和总词库。
- 展示已掌握、学习中、新词进度。
- 展示近 7 天学习热力图和未来 7 天复习量预测。
- 词库按首次学习日期分组，支持删除单词。
- 删除单词时级联删除该词的复习日志。

## 8. 数据备份

- 登录用户可从词库管理页下载自己的完整 JSON 备份。
- 文件包含格式版本、导出时间、账户邮箱、词条、当前 SM-2 状态、
  全部复习记录和个人设置。
- 不包含密码哈希、Session、验证令牌、重置令牌或 SMTP 信息。
- 导出使用一致性数据库读取，响应禁止浏览器缓存。
- 文件名格式：`vocab-backup-YYYYMMDD-HHMMSS.json`。
- v1 仅提供下载，不提供备份恢复。

## 9. 界面规范

- 白色与 `#f5f6fa` 为主背景，`#39C5BB` 为点缀色。
- 使用卡片、柔和阴影和响应式布局，适配手机与桌面。
- 导航包含仪表盘、导入单词、资料广场、今日测验、词库管理和退出登录。
- 所有交互错误必须提供明确的中文提示。

## 10. 运行与验收

- 依赖通过 `pip install -r requirements.txt` 安装。
- `python app.py` 必须成功监听 `0.0.0.0:6657`。
- 自动化测试覆盖账户、验证、密码重置、用户隔离、导入令牌、
  拼写建议、SM-2、数据备份和未登录访问控制。
- 完成后提交信息为 `Complete vocab builder v1`。
